# C# Fundamentals

A structured collection of C# fundamentals, examples, exercises, and practice code focused on building a strong foundation in C# and .NET development.

This repository follows my personal C# learning roadmap and tracks my progress from fundamental programming concepts to advanced C# features.

---

## 🎯 Learning Goal

Build a strong understanding of C# fundamentals and gradually progress toward advanced C# concepts that are commonly used in real-world .NET development.

The goal is to understand the language and its underlying concepts through hands-on practice rather than relying solely on frameworks or tools.
